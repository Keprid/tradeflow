Step 1 — Choose the analysis
Analysis type
 Auto-detect reads the country and report year from your files. Pick a country only if the detection picks the wrong one — the run stops if the data does not match the config you choose.
 Enter a market to get the exact ITC Trade Map download checklist and a matching country config for it. Leave empty and the country is read from the files you upload.
 Services Brief: the configuration is set automatically to services_world (global services trade).
 Export Performance: the newest year in the data becomes the review year and is compared with the same months one year earlier. Every sheet is read individually; pivot and summary sheets are skipped. Market tables default to 25 rows.
 Review period *: choose the months the report covers — no default is preselected. The comparison is always the same months one year earlier.
 Product Profile: the product family is auto-detected from the matrix files — choose a specific profile below only if you prefer one. Output is a Word report plus an editable Excel deliverable.
 Competitor Analysis: run this after the goods report — that first run tells you which products matter. Output is COMPETITOR ANALYSIS as .png (paste-ready), .docx and .xlsx: products ranked by import value, top exporters with value & share, Kenya highlighted in red. The tariff column is left empty.
